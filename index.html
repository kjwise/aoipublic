Architects of Intent

Online book on Software Development as Code (SDaC): build reliable, auditable GenAI systems with deterministic context, gates, and verifiable loops.

If you’re an engineer or technical leader shipping LLM features into production, this book focuses on mechanisms: how to keep context aligned with code, how to validate outputs, and how to scale from one loop to a governed system.

What you’ll find here

  • Chapters in order (use the Table of Contents)
  • A “Concepts” page for key terms and definitions
  • Practical patterns you can implement with standard tools (files, Git, make, and Python)
