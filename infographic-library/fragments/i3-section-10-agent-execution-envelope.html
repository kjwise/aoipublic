Agent (Constrained Execution Envelope)

An Agent is not “the model.” It is mission context + tools + deterministic gates + a ledger. The model is only the stochastic center; capability is granted by boundaries, not by vibes.

Execution path
Mission → Agent → Tool Runner → Gates → Ledger Context lives in the Mission object and Tool Runner (deterministic prep). Gates + Ledger are deterministic validation. This is the Deterministic Sandwich in motion. If any gate fails, action is blocked or escalated. This is why the system remains governable as autonomy rises.
